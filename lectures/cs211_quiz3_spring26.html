Quiz Questions

Question 1: What is the Model Context Protocol (MCP)?

    1. A protocol that allows LLMs to be trained on new data without retraining
    1. A standard that enables LLMs to safely connect to and interact with external data sources and tools
    1. A method for compressing the context window to make LLMs faster
    1. A security framework that prevents LLMs from accessing any external systems

Question 2: Which of the following is a primary benefit of using tools with an LLM?

    1. Tools allow the LLM to permanently update its training data
    1. Tools eliminate the need for a system prompt
    1. Tools allow the LLM to perform actions beyond generating text, such as reading files, querying databases, or calling APIs
    1. Tools reduce the cost of using an LLM by 50%

Question 3: In a database, what is a primary key?

    1. The first column in a table
    1. A unique identifier that guarantees each row in a table can be uniquely identified
    1. The key used to encrypt sensitive data in a database
    1. A key that can contain null values to represent missing data

Question 4: What is a foreign key in a relational database?

    1. A key stored outside the database on a physical key drive
    1. A column that references the primary key of another table, creating a relationship between tables
    1. A backup key kept in a separate database for security
    1. A key that is only accessible to users from other countries

Question 5: What is OpenCode in the context of LLM tools?

    1. An open-source programming language for building LLM applications
    1. An agentic LLM harness that allows LLMs to interact with and manipulate files, folders, and other system resources
    1. A database system that stores only publicly available code
    1. A method for making LLM prompts visible to end users

Question 6: You want an LLM to fetch the current weather and then suggest what clothes to wear. Which of the following would you need?

    1. A chain of thought prompt only
    1. A tool that connects to a weather API and a tool to access the user’s closet
    1. A tool that can call a weather API to retrieve current conditions
    1. A system prompt that contains all possible weather conditions

Question 7: What is a connector?

    1. A physical cable that connects a computer to the internet
    1. Another word for an MCP—a connection between an LLM and an external system or data source (like a database or file system)
    1. A prompt that tells the LLM to connect two ideas together
    1. A person who helps you debug LLM responses

Question 8: Looking at the Enrollments table above, why is it structured with 2 foreign keys instead of storing all data in one Students table?

    1. To make the database slower so users have time to read the data
    1. To avoid duplicating course information and allow students to enroll in multiple courses without repeating course details
    1. To prevent students from taking the same course twice
    1. To require an LLM to join tables together before answering queries

Question 9: An LLM is connected to a tool that can query a database. A user asks: “What are the top 5 customers by total spending?” What should the LLM do?

    1. Make up realistic customer names and spending amounts
    1. Use the database tool to query the actual data and return real results
    1. Refuse to answer because the LLM doesn’t have direct database access
    1. Ask the user to manually run a database query first

Question 10: What is the main advantage of using MCPs to connect an LLM to a database rather than embedding the entire database contents in the system prompt?

    1. MCPs are cheaper to use
    1. MCPs allow the LLM to query only the data it needs, keeping the context window free for conversation and reasoning
    1. MCPs prevent the LLM from ever making mistakes
    1. MCPs allow the database to update the LLM’s training data automatically

Question 11: You are building a system where users can ask an LLM questions about their personal files (documents, spreadsheets, etc.). Which technology would you need?

    1. A system prompt that contains all possible file paths
    1. An MCP connector to the user’s file system and a tool that can read and analyze files
    1. A foreign key relationship between the user and their files
    1. A chain of thought prompt that lists every file in the system

Question 12: In the example database above, if you wanted to find “all courses that Alice is enrolled in”, you would need to:

    1. Look only in the Students table
    1. Look only in the Courses table
    1. Query the Enrollments table using her student_id, then join with the Courses table to get course names

Question 13: What should happen if you try to insert a record with a foreign key value that doesn’t exist in the referenced table?

    1. The database should silently ignore the foreign key
    1. The database should automatically create a matching record in the referenced table
    1. The database should reject the insertion to maintain data integrity
    1. The LLM should override the database constraint

Question 14: An LLM is using OpenCode to help a user debug their Python script. What can OpenCode do that a regular chat interface cannot?

    1. Create a PDF file of the conversation
    1. Execute the code in a sandboxed environment and show the output or error messages in real-time
    1. Train the LLM on the user’s code
    1. Automatically upload the code to GitHub

Question 15: A company wants to give an LLM access to their customer database so it can answer customer service questions like “What was my last order?” Which of the following is the most secure approach?

    1. Give the LLM the database admin password
    1. Copy the entire customer database into the LLM’s system prompt
    1. Use an MCP with a connector that allows the LLM to query only specific, pre-approved data and cannot delete or modify records
    1. Disable all security checks so the LLM can access the database freely

Question 16: An AI App sends a user prompt and a list of available tools to an LLM. Describe in your own words what happens next. Include: what the LLM decides, how the tool gets called, what happens after the tool runs, and how the final answer reaches the user.
